# The Alma Pub Website Prototype

Static GitHub Pages prototype for The Alma, Sidcup.

## Files

- `index.html` - the full one-page website prototype
- `styles.css` - the approved cream / burgundy pub theme
- `script.js` - mobile menu toggle

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files into the repository root.
3. Go to Settings > Pages.
4. Set Source to Deploy from a branch.
5. Set Branch to `main` and Folder to `/root`.
6. Save and wait for GitHub to publish the site.

## Notes

This is a prototype only. Final content, event dates, menu details and imagery should be checked before live use.
